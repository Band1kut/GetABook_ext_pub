# GetABook

Расширение для `Chrome`, `Edge`, `YandexBrowser` (браузеры на базе Chromium), которое добавляет на страницы сайтов с аудиокнигами кнопку для скачивания книги.

> **Важно:** расширение не хранит и не распространяет контент, не обрабатывает и не хранит пользовательские данные. Оно лишь автоматизирует скачивание файлов, которые уже доступны на странице, и не обходит платные подписки или блокировки.

---

## Возможности

- **Поиск по сайтам** — в попапе можно выбрать, какие сайты учитывать при поиске через Яндекс или Google.
- **Кнопка скачивания** — появляется прямо на странице книги возле обложки.
- **Возобновление и пропуск** — уже скачанные файлы не загружаются повторно.
- **Прогресс и отмена** — прогресс отображается на кнопке, скачивание можно прервать.
- **Обложка и описание** — сохраняются в папку с книгой.

## Поддерживаемые сайты
Список может меняться — актуальная версия всегда в окне поиска и в `manifest.json`.

## Установка

1. Скачайте или клонируйте репозиторий или готовый [архив из релизов](https://github.com/Band1kut/GetABook_ext_pub/releases/latest) и распакуйте в удобное место.
2. Откройте страницу управления расширениями:
   - Chrome - `chrome://extensions/`
   - Edge   - `edge://extensions/`
   - YandexBrowser - `browser://extensions/`
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение** и выберите папку с проектом.
6. Для удобства закрепите иконку на панели инструментов.

## Использование

1. Нажмите на иконку расширения, чтобы открыть попап.
2. Введите название книги и выберите поисковик (Яндекс или Google).
3. При необходимости настройте список сайтов в разделе «Настройка сайтов».
4. Перейдите на страницу книги на одном из поддерживаемых сайтов — кнопка «Скачать книгу» появится рядом с обложкой или в специальном контейнере.
5. Нажмите кнопку и дождитесь завершения загрузки.
